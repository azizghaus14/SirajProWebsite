# Siraj Pro — Website

The official marketing website for **Siraj Pro**, a prayer-times app for iOS.

🌐 **Live:** [www.sirajpro.app](https://www.sirajpro.app)

Designed and built by Syed Muhammad Aziz Ghaus.

## About

A fast, static marketing site (HTML, CSS, and vanilla JavaScript — no build step) that
showcases the Siraj Pro app and hosts the pages required for the App Store listing.

| Page | Purpose |
|------|---------|
| `index.html` | Home — hero, features, widgets, themes, and pricing |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Use & subscription terms |
| `support.html` | Help center & FAQ |

Supporting files: `styles.css` (design system), `script.js` (animations, mobile nav,
theme picker, widget preview), and `assets/` (logos, screenshots, and graphics).

## Run locally

```bash
# from the project root
python3 -m http.server 8000
# then open http://localhost:8000
```

Or simply open `index.html` in a browser.
